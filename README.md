# 🎡 Колесо Фортуны

Интерактивное веб-приложение "Колесо Фортуны" с анимированным вращением и модальными окнами результатов.

## 📋 Описание

Приложение представляет собой колесо с 36 секторами, включая:
- **29 секторов с очками**: от 350 до 1000
- **7 специальных секторов**:
  - **П** — Приз
  - **+** — Плюс
  - **К** — Ключ
  - **Ш** — Шанс
  - **Б** — Банкрот
  - **0** — Ноль
  - **×2** — Удвоение

## 🛠 Технологии

- **React 18** — библиотека для создания пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Vite** — быстрый сборщик и dev-сервер
- **Tailwind CSS 4** — utility-first CSS фреймворк
- **Framer Motion** — библиотека для анимаций
- **Lucide React** — набор иконок

## 📦 Установка

### Требования

- **Node.js** версии 18 или выше
- **npm** (устанавливается вместе с Node.js)

### Шаги установки

1. **Клонируйте репозиторий** (если применимо):
   ```bash
   git clone <url-репозитория>
   cd <папка-проекта>
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

## 🚀 Запуск

### Режим разработки

Запустите dev-сервер для локальной разработки:

```bash
npm run dev
```

После запуска откройте браузер и перейдите по адресу, указанному в терминале (обычно `http://localhost:5173`).

### Сборка для продакшена

Соберите оптимизированную версию приложения:

```bash
npm run build
```

Результат сборки будет находиться в папке `dist/`.

### Проверка типов TypeScript

Проверьте код на наличие ошибок типов:

```bash
npm run typecheck
```

## 🎮 Как использовать

1. Нажмите кнопку **"Крутить"** для запуска вращения колеса
2. Дождитесь остановки колеса (около 5 секунд)
3. Просмотрите результат в модальном окне
4. Нажмите **"Продолжить"** или кликните вне модального окна для закрытия

## 🎨 Особенности

- **Плавная анимация** вращения с easing-функцией
- **Адаптивный дизайн** — корректно отображается на мобильных устройствах
- **Случайный результат** — каждый спин генерирует случайный сектор
- **Специальные сектора** с уникальными названиями
- **Модальное окно** с анимацией появления результата
- **Доступность** — кнопка блокируется во время вращения
